# Practical solutions (P1–P13)

Each folder contains the solution for one practical. HTML/CSS practicals include files that can be opened directly in a browser. Git and terminal practicals include step-by-step commands and explanations in their README files.

## Run an HTML/CSS practical
1. Open its folder.
2. Open `index.html` in a browser.
3. Keep linked CSS files in the same folder as the HTML file.

## Important
The supplied course PDF lists practical titles only. These solutions are complete examples designed around those titles; adjust personal details and any instructor-specific requirements before submission.
