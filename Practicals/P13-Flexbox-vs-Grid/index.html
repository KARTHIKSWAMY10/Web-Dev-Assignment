CSS LAYOUT GUIDE

Flexbox or Grid?

Choose a layout tool based on how your content needs to flow.

Flexbox

Best for arranging items in one direction: a row or a column.

  • Navigation bars
  • Button groups
  • Header alignment

CSS Grid

Best for layouts controlled in two dimensions: rows and columns.

  • Photo galleries
  • Dashboard layouts
  • Newspaper columns
