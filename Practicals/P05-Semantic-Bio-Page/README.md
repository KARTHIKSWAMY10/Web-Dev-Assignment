# P5 – Semantic bio page

Open `index.html` in a browser. Replace the sample name, biography, interests and email with your own details.

## Semantic elements used
- `header`: introductory content.
- `main`: the page's primary content.
- `section`: groups related biography information.
- `footer`: contact and copyright information.
- `address`: contact information.

Semantic elements describe the purpose of page content and make its structure clearer to browsers and assistive technologies.
