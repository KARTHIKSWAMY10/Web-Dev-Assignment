## How to run the practicals

- For HTML/CSS practicals, open the practical folder and launch its `index.html` file in a browser.
- Keep each practical's CSS file in the same folder as its HTML file.
- For P1–P4, follow the terminal commands in that practical's `README.md`. Run Git commands from your own project directory.
